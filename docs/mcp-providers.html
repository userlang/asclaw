MiniMax MiniMax MCP
📦 stdio 部署AI 生成需 API Key
uvx minimax-mcp（平台 npm/PyPI 提交）

MiniMax 官方多模态生成：音乐创作、视频生成、语音合成与声音克隆，AI 创作首选。

官方提供 uvx/npx 包（MINIMAX_API_KEY 用 api.minimaxi.com 国内站 Key）；经平台部署后即远程 HTTP

接入小抄：
· 国内厂商基本都要「免费注册的 Key」——正好走平台的「需配置 Token」+ 个人/企业凭证体系；各厂商鉴权方式不同（X-API-KEY / Authorization Bearer / ak= 查询参数 / X-QW-Api-Key），添加时照卡片 hint 填。
· ak 拼在 URL 里的（百度地图）不需要额外 Header；Header 型的把 Header 名和值一起录进平台凭证。
· 飞书/钉钉是 OAuth 流，平台暂不支持授权跳转，建议二选一先放，或用 tenant_access_token 试接。

· 飞常准 — 航班动态 MCP（mcp.variflight.com 域名在，端点在开放平台申请后下发）
· 彩云天气 — 天气类型备选（mcp.caiyunapp.com 域名在但本机 TCP 超时）
